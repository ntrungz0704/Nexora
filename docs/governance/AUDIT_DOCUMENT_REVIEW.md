## 3. Reconciled Conflicts & Official Nexora Baseline

Where earlier Phase-0 audit recommendations differed from approved Nexora project mandates, the following official decisions apply across **all** Nexora files:

| Conflict Topic          | Earlier Audit Output (`audit-output/`)                                   | Approved Nexora Official Rule                                                                                                                       | Resolution Status                         |
| ----------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **Backend & ORM Stack** | Option A: Laravel 12 (PHP); Option B: Next.js + NestJS                   | **Node.js + TypeScript + Express.js + Prisma ORM + Swagger/OpenAPI** (NO PHP, Laravel, NestJS)                                                      | `Approved` (ADR / Decision Log `DEC-001`) |
| **Frontend Stack**      | Laravel Blade / Inertia React or Next.js 15                              | **ReactJS + Vite + TypeScript + Tailwind CSS + React Router + TanStack Query + React Hook Form + Zod** (NO Next.js, NO Angular)                     | `Approved` (`DEC-002`)                    |
| **Database Engine**     | MySQL 8.4 or PostgreSQL 16                                               | **MySQL 8.4 LTS** managed strictly via **Prisma Migrate & Prisma Client** (NO PostgreSQL, NO MongoDB)                                               | `Approved` (`DEC-003`)                    |
| **Testing & Tooling**   | PHPUnit / Pest / PHPStan vs Vitest                                       | **npm Workspaces, ESLint, Prettier, Vitest, Supertest, Playwright**                                                                                 | `Approved` (`DEC-004`)                    |
| **Business Model**      | Single store initially + future `store_id` SellerMargin multi-store SaaS | **Single-vendor E-commerce & Store Management System for ONE store** (`Guest`, `Customer`, `Seller` = internal staff, `Admin`); **NOT Marketplace** | `Approved` (`DEC-005`)                    |
| **Git Branch Model**    | `main`, `develop`, `feature/*`                                           | **Exactly 6 initial branches:** `main`, `trung`, `hieu`, `kim`, `dinh`, `phuc` (`main` = protected integration branch via PR)                       | `Approved` (`DEC-006`)                    |
