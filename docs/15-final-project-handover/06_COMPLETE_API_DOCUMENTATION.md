## 2. Đặc tả hành vi các nhóm API trọng yếu

- **Auth (`/api/v1/auth`):**
  - `POST /login`: Body `{ email, password }` → `{ user, token }` (JWT HS256, 7 ngày). Trả `401` sai mật khẩu, `403` tài khoản bị khóa.
  - `POST /register`: Body `{ fullName, email, password, phone? }` → Tạo user role `CUSTOMER` + tạo `Cart` rỗng → `201`.
  - `POST /forgot-password`: Body `{ email }` → Luôn trả `200` generic message (chống email enumeration), gửi link qua SMTP/Nodemailer, không leak token. Trả `500 EMAIL_DELIVERY_FAILED` nếu SMTP lỗi.
  - `POST /reset-password`: Body `{ token, newPassword }` (min 8 ký tự) → Kiểm tra JWT `purpose === 'password_reset'` và `hashSig` nguyên tử (chống replay & concurrency).
- **Orders (`/api/v1/orders`):**
  - `POST /`: Optional auth; tạo đơn hàng từ `items` hoặc giỏ hàng user trong 1 `prisma.$transaction`, giảm kho điều kiện nguyên tử (`updateMany where stockQuantity >= qty`) theo thứ tự `productId` tăng dần chống deadlock, ghi `InventoryLog`, tăng `coupon.usageCount`, dọn `CartItem`.
  - `GET /track?code=&phone=`: Xác thực khớp cả `orderCode` và `customerPhone`.
  - `GET /detail/:code`: **[SECURITY FINDING — HIGH]** Không kiểm tra auth hay SĐT/email, trả về đầy đủ PII đơn hàng.
  - `POST /:code/cancel`: `requireAuth()`, kiểm tra `order.userId === req.user.sub`, chỉ hủy khi `PENDING` hoặc `CONFIRMED`, hoàn kho & ghi `InventoryLog`.
- **Payment (`/api/v1/payment`):**
  - `POST /vnpay/create-url`: Lấy số tiền trực tiếp từ DB `order.totalAmount`, kiểm tra ownership (User hoặc Guest email/phone), ký HMAC-SHA512 theo chuẩn VNPay 2.1.0.
  - `GET /vnpay/callback`: Kiểm tra chữ ký HMAC-SHA512, đối chiếu `vnp_Amount === totalAmount * 100`, xử lý idempotent nếu đã `PAID`, cập nhật `paymentStatus='PAID'` & `orderStatus='CONFIRMED'`.
  - `POST /simulate`: Chỉ mount khi `NODE_ENV !== 'production'` và chặn thêm trong `PaymentService`.
