## 2. Các cơ chế bảo mật ĐÃ triển khai tốt (Verified Controls)

- **Password Hashing:** `bcryptjs` (10 salt rounds), không lưu plaintext.
- **Anti-Email-Enumeration & Reset Token Hardening:** `POST /auth/forgot-password` luôn trả generic 200 message, gửi token out-of-band qua Nodemailer, KHÔNG trả token trong HTTP response, sử dụng `hashSig` + conditional atomic `updateMany` ngăn replay và concurrent reset (đã xác minh bởi 8 test bảo mật).
- **Chống SQL Injection:** 100% truy vấn nghiệp vụ dùng Prisma ORM parameterized queries.
- **HTTP Hardening:** `helmet()`, `app.disable('x-powered-by')`, CORS allowlist nghiêm ngặt, giới hạn body JSON `1mb`, error handler không rò rỉ stack trace.
- **Payment Security:** VNPay `vnp_Amount` tính từ DB `order.totalAmount` (tuyệt đối không tin client), xác thực ownership User/Guest, kiểm tra amount mismatch và idempotency trên callback, chặn `/payment/simulate` khi `NODE_ENV === 'production'` (13 test bảo mật pass).
- **Atomic Inventory:** Chống race condition overselling bằng conditional `updateMany` trong InnoDB transaction (đã test bằng `Promise.all`).
